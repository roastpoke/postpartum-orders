# 月子中心订单管理系统（PWA版）

> **3天交付，成本为0，功能齐全**

---

## ✨ 核心功能

### 1. 防抢单机制
- ✅ 订单自动分配给创建者
- ✅ 创建者信息不可修改
- ✅ 员工只能查看自己的订单

### 2. 防重复提交
- ✅ 24小时内相同电话自动检测
- ✅ 重复时显示已有订单信息
- ✅ 提示录入人和录入时间

### 3. 权限隔离
- ✅ 普通员工：只能看自己的订单
- ✅ 主管/管理员：可以查看所有订单
- ✅ 数据完全隔离，互不干扰

### 4. 完整功能
- ✅ 操作记录（自动记录创建时间）
- ✅ 数据导出（导出Excel）
- ✅ 筛选搜索（按状态、时间筛选）
- ✅ PWA支持（可安装到手机桌面）
- ✅ 离线支持（无网络时也能使用）

## 🚀 快速开始

### 部署步骤（30分钟）

#### 1. 准备工作（5分钟）
- 注册GitHub账号
- 注册Vercel账号

#### 2. 上传代码（10分钟）
- 将代码上传到GitHub
- 或直接拖拽到Vercel

#### 3. 部署上线（10分钟）
- 在Vercel导入项目
- 自动部署，获得访问链接

#### 4. 生成二维码（5分钟）
- 将链接转换为二维码
- 员工扫码即可使用

**详细教程请查看：[DEPLOY.md](./DEPLOY.md)**

## 🔒 技术栈

- **前端**：纯HTML + CSS + JavaScript
- **后端**：Vercel Serverless Functions
- **存储**：LocalStorage（本地存储）+ 可升级为云数据库
- **PWA**：Service Worker + Manifest
- **部署**：Vercel（免费）
